# Telegram Study Schedule

Мини-приложение Telegram для общего учебного расписания.

## Что внутри
- только вкладка расписания;
- учебные дни: вторник–суббота;
- понедельник и воскресенье — выходные;
- чётная / нечётная неделя;
- 1 полугодие: сентябрь–декабрь;
- 2 полугодие: январь–июнь;
- шаблон заполнения каждого полугодия по 5 учебным дням;
- администратор может менять расписание в любое время;
- бот хранит пользователей с включёнными уведомлениями;
- бот отправляет напоминание за 10 минут до пары;
- в боте можно включить/выключить уведомления;
- `/broadcast текст` доступна только администратору.

## Время пар
1. 08:15
2. 10:00
3. 11:45
4. 13:15
5. 15:15

## Vercel Environment Variables
- `BOT_TOKEN`
- `ADMIN_TELEGRAM_ID`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `VITE_ADMIN_TELEGRAM_ID`
- `MINI_APP_URL`

## Supabase
1. Выполнить `supabase.sql`.
2. После создания Vault выполнить отдельно:
   `select vault.create_secret('ТОКЕН_БОТА', 'telegram_bot_token');`
3. Если секрет уже существует, заменить его через `vault.update_secret`.
4. Убедиться, что cron job `study-class-reminders-every-minute` существует.

## Telegram webhook
После публичного деплоя установить webhook на `/api/bot`.

Важно: Mini App должен открываться именно из Telegram. API расписания проверяет Telegram `initData`, поэтому обычное открытие URL в браузере не даёт админского доступа.
